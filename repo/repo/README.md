## Πώς τρέχω τα προγράμματα

Κάθε φάκελος περιέχει ένα ή περισσότερα ανεξάρτητα `.java` αρχεία. Από terminal:

```bash
cd Lab1-Threads-Intro/Q4-Multiples
javac Multiples.java
java Multiples
```
